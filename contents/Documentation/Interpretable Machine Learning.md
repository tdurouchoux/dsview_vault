## Summary

This book is a comprehensive guide to making black box machine learning models explainable, covering interpretable models, local and global model-agnostic methods, and neural network-specific interpretation techniques.

**Core focus**
- Targets practitioners, researchers, and students needing to interpret ML models.
- Bridges gap between simple interpretable models (e.g., linear regression, decision trees) and complex black box models.

**Interpretable models**
- Covers linear/logistic regression, GLM, GAM, decision trees, decision rules, and RuleFit.

**Local model-agnostic methods**
- Includes Ceteris Paribus plots, ICE, LIME, counterfactual explanations, scoped rules (Anchors), Shapley values, and SHAP.

**Global model-agnostic methods**
- Features PDP, ALE, feature interaction, functional decomposition, permutation/LOFO feature importance, surrogate models, and prototypes/criticisms.

**Neural network interpretation**
- Addresses learned features, saliency maps, concept detection, adversarial examples, and influential instances.

**Additional content**
- Evaluates interpretability methods, discusses future trends, and provides appendices on ML/math terms and R packages.
- 3rd edition adds LOFO, Ceteris Paribus, improved structure, practical tips, and the Palmer penguin dataset.
- Authored by Christoph Molnar, licensed under CC BY-NC-SA 4.0.
