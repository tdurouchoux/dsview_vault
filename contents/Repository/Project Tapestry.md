## Summary

Project Tapestry, led by the AI Alliance, aims to create a globally federated, open-source platform for training frontier AI models while preserving local control and sovereignty. Key technical points include:

- **Thesis**: Current frontier models are controlled by few organizations; Tapestry proposes a collaborative approach to democratize AI development using distributed training.
- **Goals**:
  1. Achieve frontier performance via global collaboration.
  2. Ensure sovereignty (data/compute control, derivative ownership).
  3. Create structural advantages (distributed ownership, sustainable funding).
- **How it works**:
  - **Consortium model**: Partners contribute to a shared base model while retaining data/compute control; improved base model is shared back.
  - **Operating model**: Decentralized contribution (local data/compute), centralized integration (core model), and trusted governance.
  - **Distributed training**: Only weights are shared; sensitive data stays local.
  - **Sovereign derivatives**: Partners can create fully owned derivative models.
- **Data catalog**: Partners contribute metadata (provenance, license, privacy, etc.) while keeping raw data local.
- **Roadmap**: Phases 0–4 (2026–2027), starting with technical milestones (cultural alignment, distributed training frameworks) and scaling to frontier models.
- **Who should join**: ML researchers, systems engineers, compute providers, governments, and institutions with relevant datasets.

**Next steps**: Get involved via learning, contributing code, or proposing data.
