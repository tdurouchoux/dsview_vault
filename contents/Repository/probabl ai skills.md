## Summary

The **probabl-ai/skills** repository provides a set of **Data Science Skills for AI agents** (e.g., Claude Code) to streamline ML experimentation. Key features include:

- **Workspace organization** and **ML pipeline building** with best practices.
- **Evaluation, testing, and auditing** of pipelines (e.g., `evaluate-ml-pipeline`, `test-ml-pipeline`).
- **Iteration loops** for experiments (e.g., `iterate-ml-experiment`, `iterate-from-skore`).
- **Tooling support** (Python stack, env management, code style enforcement).
- **Integration with Skore Hub** for experiment tracking and diagnostics.

**Installation**: Use `skore skills install` (via `skore-cli`, `uvx`, or `pixi`). Alternatively, add as a **Claude Code plugin**.

**Skills** are categorized into:
1. **ML Pipeline Lifecycle** (e.g., data exploration, pipeline building).
2. **Iteration Loop** (experiment tracking, diagnostics).
3. **Workspace & Tooling** (Python stack, env setup).
4. **API References** (Python package navigation).

Works with agents like **Claude Code, Cursor, GitHub Copilot** and models such as **Claude Opus, Qwen 3.6 30B, DeepSeek v4 Flash**.
