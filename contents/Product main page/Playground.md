## Summary

Playground is an experimental AI-powered gaming platform that lets users create custom games quickly via text prompts, no coding needed.

**Core concept**
- AI-driven game creation from text prompts
- No coding experience required
- Chat-based interface for game design

**Game creation**
- Supports popular genres (Trivia, Tower Defense, Racing, RPG, Puzzle, Action, Arcade, Casual, Maze)
- Option to build from scratch or use templates
- Rapid prototyping (minutes per game)

**Discovery & sharing**
- Community showcase with user-created games (e.g., *CATacombs*, *Coastal Cruiser*, *Steampunk Match*)
- Examples span diverse themes (ecological sims, retro puzzles, sci-fi action)

**Access**
- Subscription may be required
- Limited to select countries and users 18+
