## Summary

Tangle is an open-source, visual ML pipeline editor developed by Shopify to simplify collaborative machine learning workflow development.

**Core Features**
- Drag-and-drop editor for building ML/data pipelines without setup.
- Platform-agnostic: supports any language/framework via containerization.
- Reusable component library + custom module integration.
- Clone, edit, and run pipelines collaboratively.

**Performance & Efficiency**
- Advanced execution caching (content-based) to save time/compute costs.

**Accessibility**
- Open-source (backend: [GitHub](github.com/tangleml/tangle), frontend: [GitHub](github.com/tangleml/tangle-ui)).
- Pre-built example pipelines and documentation for quick onboarding.

## Links

- [Tangle Backend Repository](https://github.com/tangleml/tangle) : The backend repository for Tangle, containing the core codebase for the open-source, platform-agnostic ML pipeline editor. This is where users can explore, contribute, or report issues related to the backend functionality.
- [Tangle Frontend Repository](https://github.com/tangleml/tangle-ui) : The frontend repository for Tangle, providing the user interface for the drag-and-drop ML pipeline editor. Users can review, contribute, or report issues related to the frontend components.
- [Tangle Demo (Hugging Face Space)](https://tangleml-tangle.hf.space) : An interactive demo of Tangle hosted on Hugging Face Spaces, allowing users to explore the platform's features without local setup. Includes a quick-start guide for immediate experimentation.
