## Summary

Skore is an AI-powered platform that automates predictive model building with built-in validation and enterprise-grade guardrails.

**Core offering**
- AI Data Scientist that builds predictive models with statistical rigor
- Validates AI-generated ML pipelines (catches data leaks, silent errors)
- Recommends smart metrics for enterprise use cases

**Integration**
- Two-command install: `skore hub login`, `skore agent init`
- Pre-wired with opencode, Claude, and Pi
- Works with existing tools (no new tool to learn)

**Deployment flexibility**
- Any AI provider, any ML framework, any compute
- No vendor lock-in
- Deployable in private cloud, on-premise, GCP, AWS, or Snowpark
- Data stays within your VPC/account

**Target use case**
- Tabular AI for enterprises (reliable predictions, not just speed)
