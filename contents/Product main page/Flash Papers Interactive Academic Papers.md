## Summary

Flash Papers transforms static academic papers into interactive, explorable web experiences for faster, deeper understanding of ML research.

**What it is**
- Turns arXiv/ChinaRxiv links into interactive sites with scrubbable charts and diagrams.
- Supports Google, Anthropic, or OpenRouter API keys (provider pricing applies).

**Key features**
- Whole-paper reasoning in one shot (methods, figures, appendix).
- Streaming generation—no waiting for full render.
- Built-in sliders, animations, scrollytelling, and live mini-demos.

**Example papers**
- LoRA (2021): Low-rank adaptation for LLMs, WikiSQL 74.0%.
- DDPM (2020): Diffusion models, CIFAR10 9.46.
- Spurious Rewards (2025): RLVR for math reasoning, MATH-500 70.8%.
