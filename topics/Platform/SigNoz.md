SigNoz is an open-source observability platform designed to provide a unified solution for monitoring logs, metrics, traces, alerts, and dashboards. It is built on OpenTelemetry and supports high-cardinality, high-volume observability workloads. SigNoz offers enterprise-grade features such as compliance (SOC 2 Type II, HIPAA), RBAC, custom retention, ingestion controls, and data residency. It can be deployed in fully managed cloud environments, enterprise self-hosted setups, or community self-hosted configurations using Docker, Kubernetes, or Linux.
