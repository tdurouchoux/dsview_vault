A developer preview framework for building, managing, and orchestrating agent-based systems. It provides a modular plugin architecture where every capability (e.g., models, tools, skills) is treated as a swappable plugin, enabling flexible composition and customization of agent workflows. The platform includes runtime modes (Standard, Code, Minimal, Creator), traceability features (session logs, trajectory views), and a plugin ecosystem for extensibility.
