Tangle is an open-source, platform-agnostic experimentation platform designed for building, editing, and collaborating on machine learning pipelines. It features a visual drag-and-drop editor that allows users to create complex ML workflows without requiring extensive setup. Tangle supports any programming language or framework by enabling users to wrap existing code in containers. It includes advanced execution caching to accelerate experimentation and reduce compute costs. The platform is developed to democratize ML pipeline development and is built on open-source foundations, with publicly available code and repositories for contributions and issue reporting.
