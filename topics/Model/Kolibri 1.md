Kolibri-1 is a mixture-of-experts (MoE) reasoning model developed by Aleph Alpha, optimized for German and English language tasks. It supports explicit reasoning modes, tool calling, and long-context processing up to 1,048,576 tokens. The model has 78 billion total parameters with 3.46 billion active parameters per token, uses float8_e4m3fn precision for weights, and is designed for multi-step reasoning, retrieval-augmented generation, agentic tool calling, and coding. It is released under the Apache 2.0 license and is intended for integration into conversational assistants and agentic workflows.
