GCNConv is a Graph Convolutional Network (GCN) layer implemented in PyTorch Geometric. It performs convolution operations on graph-structured data by aggregating features from neighboring nodes using a normalized adjacency matrix. GCNConv is based on the work by Kipf and Welling (2017) and is widely used for semi-supervised node classification tasks. It supports both transductive and inductive learning settings.
