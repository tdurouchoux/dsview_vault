An advanced vision-language-action (VLA) model designed to translate visual information and instructions into motor commands for robots, enabling complex task execution through spatial reasoning and multi-step planning. The model supports tool orchestration (e.g., calling Google Search or user-defined functions), multi-robot collaboration, and integrates with lower-level controllers for motor execution. It features advanced video understanding for progress tracking, moment-finding, and safety benchmarks for physical agents, with variants like the high-level 'embodied reasoning' model Gemini Robotics ER 2.
