Beam is a sparse Mixture-of-Experts (MoE) model developed by Reflection, featuring 501 billion total parameters with 23 billion active parameters. It is designed for coding, reasoning, and agentic workloads, combining pretraining on 23.8 trillion tokens with high-compute reinforcement learning (RL) to achieve competitive performance. Beam emphasizes inference efficiency, achieving frontier-level results with 3–4× less compute compared to similar-sized models. It supports controllable reasoning effort, enabling users to balance token usage and performance.
