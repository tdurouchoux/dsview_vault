GLiNER (Generalist Language Model for Named Entity Recognition) is an open-source model designed for zero-shot and few-shot named entity recognition and text classification tasks. It can be used as an alternative to Jev for classification tasks, though it may not match Jev's performance across diverse tasks. GLiNER has been around since 2021 and is notable for its flexibility in handling various classification problems without task-specific fine-tuning.
