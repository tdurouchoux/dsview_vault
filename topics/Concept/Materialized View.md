A database concept where a user declares a query (often in SQL), and the system continuously maintains the result as its inputs change. A materialized view is a database object that contains the results of a query's result set and is stored for later use, much like a view. Unlike a regular view, which is dynamically generated each time it is queried, a materialized view is physically stored and can be updated incrementally, improving query performance for complex or frequently accessed data. Materialized views became a central mechanism in modern streaming analytics, enabling users to declare the result they want while the engine handles the incremental computation. Systems like Materialize, Delta Live Tables, Snowflake Dynamic Tables, and Flink Materialized Tables leverage this concept to simplify streaming pipelines and make them accessible to ordinary users.
