Agent-scale source control refers to version control systems designed to handle the unique demands of AI-driven software development, where clients (e.g., AI agents) are always online, generate code at unprecedented rates, and require scalable, low-latency operations. Unlike traditional systems like git, which assume offline clients and decentralized repositories, agent-scale systems prioritize server-side operations, minimal local state, and horizontal scalability. Key principles include client-server asymmetry, cheap incremental commits, and comprehensive API access for programmatic interactions.
