A software design approach where functionality is modularized into plugins that can be dynamically added, removed, or reconfigured. In the context of agent frameworks, this includes vendor-neutral, open standards for packaging reusable components (skills and MCP servers) into portable plugins that extend AI agents, defining shared formats for interoperability across compatible clients while allowing client-specific customization for distribution, installation, permissions, and user experience. This approach reduces duplication and adaptation efforts for plugin authors by providing a predictable structure for shared components.
