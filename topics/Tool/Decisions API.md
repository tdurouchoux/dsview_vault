An OpenAI API endpoint designed for structured decision-making. It evaluates inputs (text, images, or both) and returns typed answers such as probabilities, choices, or scores based on predefined questions. The API supports three question types: predicate (binary conditions), choice (categorical selection), and score (ordered levels). It is optimized for low-latency, high-throughput applications and integrates with OpenAI's broader ecosystem.
