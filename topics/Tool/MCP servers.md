Components that provide standardized interfaces for AI agents to interact with external systems or services, including implementations like the Figma MCP Server. They are packaged as part of plugins (e.g., described in `mcp.json` manifests) and support communication protocols such as stdio, Streamable HTTP, or legacy HTTP+SSE, enabling interoperability between agents and external tools or data sources. Specific implementations, like the Figma MCP Server, connect Figma with AI-powered coding tools for bidirectional workflows (e.g., converting code to Figma designs or bringing Figma designs into coding environments).
