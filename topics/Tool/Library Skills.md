Library Skills is a tool designed to enable AI agents to use software libraries in their intended and up-to-date manner. It ensures that AI agents are aware of the latest features, changes, and best practices in libraries by synchronizing with the library's version. This tool scans project dependencies, installs or updates AI skills (embedded within libraries), and manages symbolic links to keep skills aligned with library updates. It supports both interactive and non-interactive installations and is compatible with various environments, including Python and JavaScript/TypeScript projects.
