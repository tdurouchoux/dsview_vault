PyC (PyTorch Concepts) is a Python library designed to facilitate the implementation of interpretable and causally transparent deep learning models. It provides a modular software stack with APIs at different levels of abstraction, including no-code APIs for large-scale experiment benchmarking, high-level APIs for out-of-the-box model instantiation, mid-level APIs for defining interpretable probabilistic graphical models, and low-level APIs for building architectures with interpretable layers. The library is built on top of PyTorch and PyTorch Lightning and supports probabilistic modeling of the conditional distribution of targets given concepts (P(y|C)).
