Daft is an open-source data engine (licensed under Apache 2.0) designed for AI workloads, enabling end-to-end processing of multimodal data (e.g., video, images, audio, sensor data, and structured metadata) in a single pipeline. It integrates CPU and GPU operations seamlessly, supports native model operators (e.g., embeddings, LLM extraction), and provides a Python dataframe API similar to Pandas or Spark. Daft handles scheduling, batching, and resource management without requiring glue code, and is optimized for performance, memory efficiency, and scalability from local development to distributed cloud environments.
