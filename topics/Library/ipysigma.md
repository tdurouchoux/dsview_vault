A Jupyter widget that renders interactive network graphs using `sigma.js` and `graphology`. It integrates with `networkx` or `igraph` for graph data and provides extensive customization of visual variables (e.g., node color, size, labels, borders, halos, pictograms, shapes) and edge properties. The widget supports synchronized 'small multiples' for comparing graph features and computes metrics like Louvain partitioning directly within the widget.
