A unified and extensible framework for text classification that supports both text and categorical variables. Built on PyTorch and PyTorch Lightning, it provides modular components like `ValueEncoder`, `TokenEmbedder`, `SentenceEmbedder`, `CategoricalVariableNet`, and `ClassificationHead` for flexible model construction. It supports multiclass and multilabel classification, integrates explainability tools like Captum and label attention, and offers a simple API for training and experimentation.
