Knap is an open-source template language designed to transform structured data into Markdown documents. It supports dynamic variable insertion, conditional logic, array iteration, and customizable filters for formatting Markdown content. Knap is named after the process of knapping, which involves shaping stones into tools, symbolizing its role in shaping data into structured documents. It originated as the templating language for Obsidian and is now usable in various tools and applications.
