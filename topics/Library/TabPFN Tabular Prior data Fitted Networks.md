A machine learning library and framework for tabular data prediction based on the Prior-Data Fitted Network (PFN) architecture, enabling efficient and accurate predictions (including in-context learning) without extensive hyperparameter tuning or feature engineering. TabPFN is pre-trained on synthetic and real data, handling small to medium-sized tabular datasets with minimal computational overhead. It uses a transformer architecture to sample tasks and datasets, integrating over latent tasks for transfer learning across tabular problems. The library includes versions such as TabPFN-2.6, which is optimized for in-context learning and evaluated in benchmarks like BeyondArena for classification and regression tasks.
