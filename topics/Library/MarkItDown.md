A lightweight Python utility for converting various file formats (PDF, PowerPoint, Word, Excel, Images, Audio, HTML, Text-based formats, ZIP files, YouTube URLs, and EPubs) into Markdown, designed to preserve document structure and content for use with LLMs and text analysis pipelines. This encompasses the general process of Markdown conversion, including handling headings, lists, code blocks, tables, and formatting to maintain readability and structure.
