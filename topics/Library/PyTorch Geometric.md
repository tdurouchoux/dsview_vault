PyTorch Geometric (PyG) is an open-source library built on top of PyTorch, designed to facilitate the implementation and training of Graph Neural Networks (GNNs) and other geometric deep learning models. It provides a unified and easy-to-use API for working with graph-structured data, including support for mini-batch training, multi-GPU processing, and a wide range of GNN layers, models, and utilities. PyG is widely used for tasks such as node classification, link prediction, graph classification, and 3D point cloud processing.
