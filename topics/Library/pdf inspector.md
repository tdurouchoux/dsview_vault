A fast Rust library for PDF classification and text extraction. It detects whether a PDF is text-based, scanned, image-based, or mixed without using OCR. The library supports position-aware text extraction, converts PDFs to clean Markdown, and includes features like table detection, CID font support, multi-column layout handling, and encoding issue detection. It provides bindings for Python, Node.js, and browser WebAssembly, and is designed for local processing with low latency.
